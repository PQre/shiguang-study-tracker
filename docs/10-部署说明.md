# 部署说明

已于 2026-10-26 发布 [GitHub Pages 在线演示](https://pqre.github.io/shiguang-study-tracker/)，可直接体验学习计划、打卡、统计和分享导出。数据保存在访问者自己的浏览器中；完整 FastAPI + SQLite 后端仍按下方方式运行或部署。网站的构建、测试和版本范围见 [线上演示说明](12-线上演示说明.md)。

教材允许确有部署困难时提交主要功能截图，是否接受以本期老师要求为准。

## CloudStudio方式

1. 登录你的CloudStudio账号，创建或选择支持Python 3.11+的工作空间。
2. 上传项目源码（不要上传`.deps`、真实数据库和个人证据）。使用平台的终端进入项目目录。
3. 建虚拟环境，安装`requirements.txt`，运行`python run.py --host 0.0.0.0 --port 8000`。
4. 按工作空间当前预览／端口转发入口打开8000端口，保持平台访问保护。写入测试需要Origin与Host一致，若反向代理改写Host，应正确配置外层转发，不要关闭来源校验来掩盖配置问题。
5. 使用演示模式展示时明确说明示例数据。分享访问地址前确认该工作空间的访问范围与数据内容。

不同CloudStudio版本的界面可能不同，具体入口参考本期[部署教材](https://hypersmart.feishu.cn/wiki/ZgZEwg6sXiMMpCkrXO7c5Eg0nGb)和平台当前提示。本次未验证CloudStudio平台部署。

## Docker方式（提供配置，尚未实际构建验证）

```bash
docker build -t study-tracker .
docker run --rm -p 127.0.0.1:8000:8000 -v study-data:/app/data study-tracker
```

数据卷保留SQLite数据，访问为本机8000端口。需要公开服务时，增加经过验证的身份认证、HTTPS反向代理及数据库备份。当前源码不提供多用户隔离，不应作为开放的多人打卡服务。

## 提交前部署核对

检查健康接口、页面、创建／编辑、重复校验、PNG、CSV；重启后核对数据；保存实际访问地址与操作截图。云服务如需费用、账号条款或权限变更，由你根据账号情况决定。

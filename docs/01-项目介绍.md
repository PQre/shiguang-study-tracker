# 项目介绍：学习打卡追踪器

选题来源：教材项目实战章节推荐清单第 8 项。个人独立项目，未设置虚构团队成员。

训练营学员需要把课程主题、每日实践、分享材料和提交证据组织起来。纸面记录容易遗漏，同一日期重复记录也可能让统计失真。本项目把学习计划、每日打卡和知识点分享集中在一个可运行的应用中。

核心功能：建立学习计划；记录每日学习时长与收获；查看学习天数、连续天数和累计时长；查找 28 个知识点；核对日期后导出不附个人署名的分享 PNG；查询、修改或删除打卡；导出 CSV。

技术栈：Python 3.11+、FastAPI、SQLite、Vue 3。Vue 使用项目内保存的官方发行文件，页面运行不依赖外部 CDN。FastAPI 同源提供页面和 API。

案例特点：同一计划同一天最多一条记录；服务端拒绝未来学习日期和计划外日期；数据保存在 SQLite；所有演示数据使用独立数据库并明确标识；课程草稿不会自动成为打卡记录；提交勾选由用户主动确认，不模拟上传到群公告。

交付目标是便于个人本地使用和课堂演示。当前版本没有多用户登录与权限隔离，远程演示需使用受保护的私人工作空间。

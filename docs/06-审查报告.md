# 设计及代码审查报告

审查主体：本次 AI 辅助工程检查。此报告不代表导师已经点评或批准。

| 问题／风险 | 处理 | 验证 |
| --- | --- | --- |
| 前端限制可被绕过，重复日期会污染统计 | 服务端校验＋数据库计划／日期唯一索引 | 重复创建 409；两次请求后仍一条记录 |
| 同一天不同计划导致全局天数重复 | 统计对日期集合去重 | 两计划同日累计为 1 天，分钟正确相加 |
| 修改计划日期排除历史学习 | 更新前检查记录是否仍在区间内 | 不合法更新 409，原记录保留 |
| 删除计划可能隐式删除证据 | 外键 RESTRICT，业务层拒绝含记录的计划删除 | 删除保护测试通过 |
| 未来日期或无效日期形成假记录 | 以北京时间今天校验，Pydantic 日期解析 | 未来、计划外日期、非法日历日期拒绝 |
| SQL／HTML／CSV 输入注入 | 参数化SQL、Vue文本插值、CSV公式前缀转义 | CSV 含公式字符与逗号换行的测试通过；SQL与前端源码检查 |
| 其他网页可能向本地服务发写请求 | 校验浏览器 Origin 的主机 | 跨站写请求 403，同源成功 |
| 学习材料被误认为完成记录 | 原始库为空；知识库只读；演示库独立 | 示例页有演示声明，课程 API 不写 records |
| 长姓名与日期同一行使分享图溢出 | 姓名限制 20 字，姓名与日期分行 | 浏览器导出已验证；修改后做语法及页面刷新检查 |
| 页面切换保持旧滚动位置 | 监听页面切换并回到顶部 | 切换概览与分享后截图复核 |

已知限制：单用户版本无账户认证和权限隔离，无自动备份；数据库模式首次创建，不含升级迁移机制；未做多人并发压力测试、真实手机设备测试或公网渗透测试。模型只参与开发过程，运行时没有模型调用。

建议导师重点点评：选题是否符合本期任务；单用户范围是否合适；数据规则与验收覆盖是否充足；远程部署或功能截图是否满足本期要求。

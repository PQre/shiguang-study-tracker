# 操作手册

1. 按项目README安装依赖，启动 `python run.py`，访问 `http://127.0.0.1:8000`。首次真实模式为空；只想演示时使用 `python run.py --demo`。
2. 打开“学习计划”，点击“新建计划”，填写名称、真实开始日期、天数和每日目标。默认建议28天、45分钟，可按自己的情况调整。
3. 点击“记录学习”，选择计划，填写真实学习日期、主题、分钟、收获和下一步。今天之后的日期、计划外日期、同计划同日的第二条记录会被拒绝。
4. “学习概览”可筛选计划，查看学习日期数量、时长、连续天数、最长连续天数及本人确认的分享上传数量。全局统计按日期去重。
5. 打开“知识点分享”，按周或关键字选择文章。读教材、做小练习，再补自己的发现。核对分享日期后“导出PNG”。本版图片不附个人署名，只下载到本地，不自动发群。
6. 核对图片后，按考核要求自行上传群公告加分表；保存提交成功截图，再编辑当日记录勾选“我已上传”。该勾选只记录自述状态。
7. “打卡记录”可编辑和删除单条记录，也可下载CSV。含记录的计划不能直接删除，防止无意丢失证据。
8. 停止服务用终端 `Ctrl+C`。真实数据为 `data/tracker.db`；演示数据为 `data/demo.db`。备份前先停止服务，连同需要的分享图片一起保存。

## 常见问题

端口被占用：`python run.py --port 8001`，改访问对应端口。

提示依赖缺失：确认使用的是安装过requirements的虚拟环境Python。

页面打不开：确认服务终端仍运行，网址和端口正确。不要直接双击index.html，页面需要本地API。

打卡日期不在计划范围：修改计划范围或选择正确计划；修改范围不能排除现有记录。

图片中文字体不同：浏览器优先使用微软雅黑或系统中文字体，先查看下载图片再提交。

# 功能规格说明书 v1.0

## 范围

单用户学习打卡应用，默认真实数据库为空。演示模式通过独立数据库展示示例记录。学习日期和提交行为由用户填写，不收集个人身份信息。

## 用户故事与验收

| 编号 | 用户故事 | 可验证验收标准 |
| --- | --- | --- |
| F01 | 学员创建学习计划 | 名称 1–60 字；周期 1–90 天；每日目标 5–480 分钟；保存后刷新仍存在 |
| F02 | 学员调整计划 | 名称与目标可修改；已存在记录时修改日期区间不得排除记录 |
| F03 | 学员记录某天学习 | 选择计划、日期、主题、时长、收获与下一步；时长 1–720 分钟；日期不超过北京时间今天且落在计划区间 |
| F04 | 避免重复打卡 | 同计划同日期第二次创建返回 409；修改已有记录正常保存 |
| F05 | 学员浏览记录 | 可按计划筛选，按日期降序展示；支持编辑及确认后删除 |
| F06 | 学员理解进度 | 计划完成率按有效打卡日期／计划总天数计算；学习时长是分钟总和；全局学习天数对日期去重 |
| F07 | 学员使用知识库 | 有 28 个主题，可按周、关键字筛选；显示知识点、案例、提示词、小练习、思考问题和来源 |
| F08 | 学员制作分享图 | 缺少分享日期时阻止导出；PNG 包含日期和完整知识点，不附个人署名；不自动上传 |
| F09 | 学员导出学习记录 | UTF-8 BOM CSV，中文正常；危险公式起始字符作转义；筛选计划对应导出 |
| F10 | 学员记录分享提交 | 用户主动确认“分享已上传”；系统仅记录自述状态，提醒以助教审核为准 |

连续学习天数定义：全局或指定计划的去重日期，若最近日期是今天或昨天，从最近日期向前数连续天数，否则为 0。最长连续天数为全部历史日期中的最长连续段。同一日多个计划不会增加全局学习天数或连续天数。

## 页面

学习概览：统计、28 天网格、最近记录和快速打卡。
学习计划：创建、修改、查看进度，删除前确认；含记录的计划不可直接删除。
知识点分享：筛选、完整文章、日期编辑、导出不附个人署名的 PNG。
打卡记录：筛选、编辑、删除、导出 CSV。

## 非功能要求

服务端数据验证、参数化 SQL、数据库唯一约束和外键；页面用 Vue 文本插值避免注入原始 HTML；写请求校验 Origin，避免浏览器跨站写入本地服务；移动端适配；错误时可见提示；原生标签和键盘焦点；数据目录排除源码打包。

## 范围限制

没有云端账号、排行榜、模型 API 自动生成内容、自动提交群公告或直播统计。该应用体现 AI 辅助软件开发流程，课程知识库由教材整理而成，不声称运行时使用大模型。

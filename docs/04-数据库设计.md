# 数据库设计

SQLite 文件默认 `data/tracker.db`；`--demo` 使用 `data/demo.db`。二者互相独立。

| 表 | 字段 | 类型与约束 |
| --- | --- | --- |
| plans | id | INTEGER 主键 |
| plans | name | TEXT NOT NULL，1–60 字 |
| plans | start_date | TEXT ISO 日期 |
| plans | days | INTEGER，1–90 |
| plans | target_minutes | INTEGER，5–480 |
| plans | created_at | TEXT UTC ISO 时间 |
| records | id | INTEGER 主键 |
| records | plan_id | INTEGER 外键，删除 RESTRICT |
| records | study_date | TEXT ISO 日期 |
| records | topic | TEXT，1–120 字 |
| records | minutes | INTEGER，1–720 |
| records | takeaway | TEXT，1–1500 字 |
| records | next_step | TEXT，至多 1000 字 |
| records | shared | INTEGER，0/1，用户自述上传状态 |
| records | created_at | TEXT UTC ISO 时间 |

唯一索引 `(plan_id, study_date)` 保证每日重复创建在并发时也不成功。`study_date` 索引用于排序和统计。具体日期区间限制在业务层执行。

SQLite 使用参数化 SQL，记录内容当作普通字符串，不拼入 SQL。导出 CSV 对可能被电子表格解释为公式的字符串加前缀单引号。删计划前明确检查记录存在，防止无提示地删除学习证据。

備份：停止服务后复制数据库文件；运行中备份请用 SQLite backup API，不单独复制可能还在 WAL 中的数据。应用没有上传个人材料到外部服务。

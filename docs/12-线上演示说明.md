# GitHub Pages 在线演示

访问地址：https://pqre.github.io/shiguang-study-tracker/

## 可演示内容

学习概览、创建和调整计划、每日打卡、编辑与删除记录、去重统计、28 篇知识点、分享 PNG 和学习记录 CSV 导出。

初始加载虚构的演示计划与记录；当天记录留空，便于直接尝试打卡。访问者的修改保存在自己的浏览器 `localStorage` 中，刷新后保留。清理浏览器站点数据或点击顶部“重置示例”会恢复初始状态。页面不上传学习记录，也不与其他浏览器或 APK 同步。

## 与其他版本的关系

| 版本 | 运行与数据方式 |
| --- | --- |
| 本地网页版 | FastAPI + Vue + SQLite，运行 `python run.py` |
| GitHub Pages 演示 | 复用网页版前端，以浏览器数据层模拟 API，不运行 Python 服务 |
| 同组提供的 Android APK | 独立手机离线版本；其附件与原生功能需 Android 工程支持，不属于本次 Pages 演示 |

浏览器演示与当前网页版保持删除保护：计划有打卡记录时拒绝删除，不级联清除记录。分享图不附个人署名或原先尾部提示。演示数据的北京时间计算覆盖凌晨边界，并对浏览器存储不可用提供错误提示。

## 本地复现

在项目目录执行：

```bash
python scripts/build_demo.py
node scripts/test_demo.cjs
python -m http.server 8080 --directory .site
```

打开 http://127.0.0.1:8080/。构建目录 `.site/` 不提交到 Git。

## 自动发布

`.github/workflows/pages.yml` 在 `main` 的前端、演示层或构建脚本变化时执行：构建、验证演示行为、上传 Pages 制品、部署。也可从 Actions 手动运行。工作流只将 `.site/` 发布为网站，不发布本地数据库、个人材料或工作区临时文件。

Pages 发布源使用 GitHub Actions。若变更域名或仓库名称，需要同步 README 和此文档中的地址；页面资源使用相对路径，以兼容 GitHub 项目站点的目录前缀。

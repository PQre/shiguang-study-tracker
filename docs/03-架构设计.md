# 架构设计

```mermaid
flowchart LR
 U[浏览器 Vue 3] -->|同源 JSON| API[FastAPI 路由与校验]
 API --> S[学习统计服务]
 API --> DB[(SQLite)]
 API --> L[28 篇课程 JSON]
 U --> C[Canvas 导出分享图片]
 API --> E[CSV 导出]
```

`frontend/index.html`、`app.js`、`styles.css` 组成 Vue 单页面应用。官方 Vue 生产版文件放在 `vendor/`，脱离 CDN 运行。`backend/models.py` 定义输入模型，`database.py` 建表、连接和查询，`stats.py` 计算统计，`main.py` 处理 API 和页面请求。

采用 API 优先：先定义计划、记录和统计契约，再实现后端，再联调 Vue。前端状态来自服务端，不把真实数据存进 localStorage。知识库来自 `lessons.json`，属于应用的只读素材，不自动写入 records 表。

SQLite 适合个人项目，连接设置外键、忙等待和 WAL；每个请求创建并关闭连接，写入事务由连接上下文提交。跨计划全局统计按日期去重。服务器默认监听 127.0.0.1，写请求检查 Origin，公网部署需外层认证、TLS 与数据备份。

基础功能采用单服务同源部署，保留前后端源码分层。AI助理是可选模块，不配置时不依赖模型服务；配置后由FastAPI调用兼容Chat Completions的外部模型。密钥只在后端读取。

`frontend/assistant.js`实现分钟热力图、本地关键词检索、对话窗口及识别草稿。GitHub Pages保留浏览器本地数据层，通过单独的真实网络请求连接AI服务。`backend/ai.py`处理有边界的文本/图片请求、访问口令、来源限制、模型调用和结果校验。可用`--ai-only`单独运行AI接口，避免为公开演示开放学习数据库API。详见[接入说明](13-AI助理与热力图.md)。
